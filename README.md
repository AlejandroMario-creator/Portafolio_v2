# Portafolio web

Portafolio responsivo construido con React, Vite y Tailwind CSS v4.

## Requisitos

- Node.js 20.19+ o 22.12+
- npm

## Ejecutar en desarrollo

```bash
npm install
npm run dev
```

Vite mostrará la URL local en la terminal.

## Personalizar

- Edita nombre, iniciales y redes en `src/data/portfolio.js`.
- Actualiza las habilidades y proyectos en el mismo archivo.
- Coloca tu CV en `public/CV.pdf` para habilitar su descarga.
- Reemplaza los enlaces de ejemplo de proyectos antes de publicar.
